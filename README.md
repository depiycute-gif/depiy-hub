# De_piy Hub · 드피 허브

대화·피드·미디어를 한곳에 모은 올인원 커뮤니티. 단일 HTML로 동작하는 웹 빌드입니다.

- 라이브: https://depiycute-gif.github.io/depiy-hub/
- 인증: Supabase Auth (이메일/비밀번호)
- 스택: Vanilla JS + Tailwind CDN + Lucide + Supabase JS
- 브랜드 컬러: `#F8935F`

## 오리지널 인터랙션

| 이름 | 역할 |
| --- | --- |
| ⚡ 스파크 | 좋아요를 대신하는 시그니처 오렌지 불꽃 반응 |
| 📡 에코 | 타임라인·채널로 글을 증폭시키는 재공유 |
| 💬 라이브 스레드 | 실시간으로 쌓이는 반응 댓글 |
| 🎬 워치파티 | 영상과 음성 수다를 함께 |
| 🎙️ 플로팅 라운지 | 상단에 떠 있는 음성 라운지 |

## 로컬에서 열기

`index.html`을 브라우저로 열면 됩니다. Supabase 인증은 배포 도메인 기준으로 동작합니다.
